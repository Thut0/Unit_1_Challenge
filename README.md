# Unit 1 Challenge: Concert Ticket Booker

A beginner-level Python program that demonstrates basic input/output operations and string formatting. This project is a simple interactive ticketing system where users provide their name and select an artist to book concert tickets.

## Features

- Prompts user for their name
- Asks for their preferred artist or band
- Confirms the booking with a personalized message using Python f-strings

## How to Run

```bash
python "The Concert Ticket Booker.py"
```

Follow the on-screen prompts:
1. Enter your name
2. Enter the band or artist you'd like to see
3. Receive a confirmation message with your booking details

### Example

```
Please enter your name: Alice
Which band or artist would you like to see perform? The Beatles
Hey Alice! Your tickets to see The Beatles are booked successfully!
```

## Requirements

- Python 3.6+

## What You'll Learn

This exercise covers fundamental Python concepts:
- Using the `input()` function to capture user data
- Storing values in variables
- String formatting with f-strings
- Outputting text with `print()`

## Next Steps

Consider extending this project with:
- Input validation (e.g., checking that names aren't empty)
- Additional booking information (date, venue, ticket quantity)
- Error handling for invalid inputs
- A loop to book multiple tickets in one session
